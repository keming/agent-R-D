## 一、现在的问题

前易安（前列腺癌尿液 RNA 三类证）已经获批，销售团队开始跑医院。但实际工作中，三个问题反复出现：

| 痛点 | 真实场景 |
|------|----------|
| **记不住** | 每个产品几十个关键数字、证号、临床指标、指南条款，新人三个月才能独立见医生，老人也会记混 |
| **答不好** | 医生当场问："你们和为真生物的区别在哪？""灰区阳性预测值多少？""有没有多中心数据？"——销售翻资料翻半天，医生已经没耐心了 |
| **留不下** | 医生说了什么、拒绝了什么、竞品什么动向，都在销售个人的微信和脑子里，人一走知识就带走 |

**本质问题：昱鼎有足够的知识资产，但这些资产没有被组织成销售随时能用的形态。**

## 二、我们做什么

**一个 AI 驱动的销售知识智能体，两个入口：**

### 飞书里直接问（轻量、即时）

拜访中途，掏出手机在飞书里打一句话，10 秒内拿到答案：

```
销售：PSA 灰区人群，前易安能减少多少不必要穿刺？
  AI：根据中国多中心研究，约 35.3%。存在约 5.8% 高级别癌延迟诊断风险，
      建议结合 MRI 和临床综合判断。[数据来源：WJSO 2024]
```

### Web 端深度使用（拜访前后）

- **拜访前**：搜一下这个医院的科室专长、最近发表、竞品渗透情况，自动生成针对性开场白
- **拜访后**：口述今天聊了什么，AI 自动整理成结构化汇报，同步给市场/研发
- **日常**：全局搜索 + 按产品/竞品/FAQ 分类浏览知识库

## 三、装进系统里的知识

MVP 先聚焦前易安产品线，涵盖四个维度：

| 知识域 | 销售能查到什么 |
|--------|---------------|
| **产品与证据** | 三类证号、灵敏度/特异性/NPV/PPV、临床定位、指南收录、近万例验证概况 |
| **竞品对比** | 和为真生物的证号、适应症、审评表述逐项对比；和传统 PSA/穿刺路径的优劣势；和 MRI 靶向穿刺的场景划分 |
| **FAQ 问答** | 医生最常问的 100+ 个问题，每条有标准回答 + 引用来源，持续更新 |
| **拜访支持** | 话术模板、按医院等级/科室偏好的推荐切入点、学术推广素材库 |

## 四、为什么现在做

三个理由：

1. **窗口期不等人。** 为真生物同类三类证 2025 年 5 月获批，差距只有 3 个月。接下来比的不是谁先拿证，而是谁先进指南、谁先进医院。销售能力是决胜变量。

2. **知识资产已经到位。** 七年研发、近万例验证、多中心合作，昱鼎不缺"料"，缺的是把"料"变成一线火力的通道。这个系统恰好是那个通道。

3. **成本可控，效果可量化。** 不需要组建 AI 部门，不需要自研大模型。用成熟技术 + 昱鼎现有知识内容，两个月内交付可用版本。

## 六、技术怎么实现（简述）

技术方案一句话：**不造大模型，用成熟 RAG 技术 + 昱鼎自有知识内容。**

| 环节 | 做法 |
|------|------|
| 知识入库 | 把昱鼎现有的 PDF、Word、飞书文档、FAQ 表自动解析成结构化知识 |
| 智能检索 | 销售提问 → 语义匹配 → 找到最相关的知识片段 |
| 答案生成 | 大模型把知识片段组织成通顺回答，绝不凭空编造 |
| 持续更新 | 新产品信息、新竞品动态、销售一线反馈 → 审核后即时入库 |

**安全底线：** AI 回答全程标注来源，核心数据（证号、临床指标）100% 可溯源；医学事务部定期抽检准确性。
