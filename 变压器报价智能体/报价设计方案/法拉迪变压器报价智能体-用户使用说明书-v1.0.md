## 1. 系统概述

### 1.1 系统定位

法拉迪变压器报价智能体是一个面向销售、报价工程师和技术工程师的**智能报价工作台**。它将客户提供的非结构化需求（邮件、Word、截图、PDF、Excel、语音等），转化为标准化的变压器参数，再辅助匹配历史计算单、生成参数包，并逐步扩展到BOM成本、报价审批和知识沉淀。

> **核心价值**：把7-15天的报价流程压缩到**30分钟以内**。

### 1.2 解决什么问题

| 痛点 | 传统方式 | 使用本系统后 |
|:----|:---------|:------------|
| 客户需求不标准、不完整 | 人工反复沟通确认，来回2-3天 | AI自动解析，一键生成澄清问题清单 |
| 历史计算单难找 | 靠个人记忆，经常找不到或找到不敢用 | 自动匹配A/B/C/D四级复用，差异项一目了然 |
| BOM成本计算繁琐 | 手工拆解、逐项核算，易出错 | 自动导入BOM，实时物料价格匹配 |
| 报价审批流程长 | 纸质流转，平均2-3天 | 全线上四级审批，自动版本管理 |
| 经验无法沉淀 | 人员流动带走经验 | 每次报价自动回流，越用越准 |

### 1.3 系统全貌：五阶段架构

| 阶段 | 名称 | 做什么 | 谁用 |
|:----:|:----|:-------|:----:|
| **第一阶段** | 需求解析与参数包智能体 | 客户需求 → 标准参数表 → 参数包 | 销售、报价工程师 |
| **第二阶段** | 计算单匹配与设计协同智能体 | 历史计算单匹配 → 四级复用 → 差异分析 | 报价工程师、技术工程师 |
| **第三阶段** | BOM成本与多方案报价智能体 | BOM导入 → 成本测算 → 多方案比价 → 报价草稿 | 成本人员、报价工程师 |
| **第四阶段** | 正式报价审批与客户文件智能体 | 四级审批 → 版本管理 → 文件包导出 | 审批人、销售 |
| **第五阶段** | 知识沉淀与持续优化智能体 | 数据回流 → 知识飞轮 → 越用越准 | 系统自动运行 |

## 2. 目标用户与角色

| 用户角色 | 主要诉求 | 在系统中的主要任务 |
|:---------|:---------|:------------------|
| **销售人员** | 快速整理客户需求，减少反复问技术 | 上传需求文件、确认商业字段、查看澄清问题、下载报价单 |
| **报价工程师** | 形成可计算、可报价的参数包 | 复核参数、匹配历史计算单、发起技术确认、导出参数包 |
| **技术工程师** | 保证关键工程参数正确 | 确认电压、损耗、阻抗、结构、套管、绝缘等工程字段 |
| **成本人员** | 确认BOM和价格依据 | 确认物料价格、汇率、毛利，审核成本测算 |
| **审批人** | 控制正式报价风险 | 四级审批流（技术→商务→总经理），管理报价版本 |
| **管理员** | 维护系统基础规则 | 维护字段字典、同义词、阻断规则、计算单匹配规则 |

## 3. 快速上手：完成第一次报价

### 3.1 标准操作流程

```
① 新建报价项目
        ↓
② 上传客户需求（或粘贴邮件正文）
        ↓
③ 系统自动解析需求（30秒-2分钟）
        ↓
④ 查看解析结果：参数表 + 缺失/冲突/风险标记
        ↓
⑤ 销售确认商业字段（客户、币种、有效期等）
        ↓
⑥ 系统生成澄清问题 → 发给客户确认
        ↓
⑦ 技术确认关键工程字段
        ↓
⑧ 导出计算单参数包 → 发给电磁计算团队
        ↓
⑨ （第二阶段以后）匹配历史计算单 → BOM成本 → 报价审批 → 输出正式报价
```

### 3.2 第一步：新建报价项目

1. 登录系统后，默认进入**报价项目列表**页面
2. 点击右上角 **「新建项目」** 按钮
3. 填写基本信息：
   - 项目名称（建议含客户名+日期，如"苏丹电力局-20260707"）
   - 客户名称
   - 国家/地区
   - 币种、税率、报价有效期
4. 点击 **「创建」**，进入需求输入页面

### 3.3 第二步：上传客户需求

在需求输入页，您可以通过以下方式提交客户需求：

- **粘贴邮件正文**：直接复制客户邮件中的需求描述粘贴到文本区
- **上传文件**：支持Word（.docx）、图片（.jpg/.png）、PDF、Excel（.xlsx）
- **多附件**：可同时上传多个文件，系统会自动合并解析

点击 **「开始解析」** 按钮，系统开始AI解析，通常30秒-2分钟内完成。

> **提示**：如果客户需求较长，建议优先使用文件上传，解析准确率更高。

### 3.4 第三步：查看解析结果

解析完成后，自动进入**解析工作台**。工作台采用三栏布局：

```
┌───────────────────┬───────────────────┬───────────────────┐
│   左侧：原文区     │   中间：参数区     │   右侧：风险区     │
│                   │                   │                   │
│  客户原始文件展示   │  项目级参数        │  缺失字段          │
│  点击字段高亮来源   │  产品行参数（表格）  │  冲突字段          │
│  多附件切换        │  字段颜色标记状态    │  高风险字段        │
│                   │                   │  待确认问题        │
└───────────────────┴───────────────────┴───────────────────┘
```

**重点检查：**
- **左侧**：确认原始文件是否正确上传、完整展示
- **中间**：检查AI解析出的参数是否准确（容量、电压、损耗、阻抗等）
- **右侧**：查看缺失字段和冲突字段，这些需要您手动确认或向客户澄清

### 3.5 第四、五步：确认字段与澄清问题

1. **销售确认商业字段**：在参数区确认客户名称、币种、税率、报价有效期等商业信息
2. **查看澄清问题**：右侧「澄清问题」区域自动列出了需要向客户确认的问题
3. **一键复制**：点击问题右侧的复制按钮，可一键复制为邮件或微信文本，发给客户确认
4. **技术确认工程字段**：技术工程师逐一确认电压等级、损耗要求、阻抗范围等关键工程字段

> **注意**：标注为红色（缺失/冲突/阻断）的字段，在未解决前不允许导出参数包。

### 3.6 第六步：导出参数包

所有必填字段确认完成后，进入**参数包导出页**，可选择以下格式导出：

| 格式 | 用途 |
|:----|:-----|
| **Excel** | 发给电磁计算团队，可直接导入优化计算软件 |
| **Word** | 存档或发送给客户确认参数清单 |
| **JSON** | 系统间数据交换格式 |
| **计算软件导入模板** | 直接导入法拉迪电磁计算引擎 |

## 4. 核心页面详解

### 4.1 报价项目列表

**入口**：登录系统首页

**功能**：
- 查看所有报价项目和当前状态
- 按客户、国家、销售、日期筛选查询
- 快速查看项目风险数量（数字标红表示存在未解决的阻断项）
- 点击列表项进入对应项目的解析工作台

**状态标识**：

| 状态 | 含义 | 下一步操作 |
|:----|:-----|:-----------|
| 待解析 | 已创建项目，尚未上传需求 | 上传需求并点击「开始解析」 |
| 待销售确认 | AI解析完成，待销售确认商业字段 | 检查并确认商业信息 |
| 待技术确认 | 商业字段已确认，待技术审核工程参数 | 技术工程师逐项确认 |
| 参数包已生成 | 全部确认完成，可导出 | 下载参数包 |

### 4.2 解析工作台

**三栏布局详解：**

**左侧——原文区：**
- 展示客户上传的原始文件内容（文本高亮显示）
- 点击中间参数区的任意字段，左侧自动高亮显示该字段的原文来源位置
- 支持在多个附件之间切换查看

**中间——参数区：**

分为两块：

**项目级参数**（全局共享的参数）：

| 字段 | 说明 |
|:----|:-----|
| 执行标准 | IEC 60076 / IEEE / 客户自定义 |
| 环境条件 | 户外/户内、最高温度、湿度、防腐等级 |
| 联结组别 | Dyn11 / Yyn0 等 |
| 冷却方式 | ONAN / ONAF |
| 频率 | 50Hz / 60Hz |

**产品行参数**（每个型号/方案独立参数，以表格展示）：

| 字段 | 说明 | 示例 |
|:----|:-----|:-----|
| 容量(kVA) | 产品规格 | 75 |
| 高压电压(V) | — | 13200/7200 |
| 低压电压(V) | — | 120/240 |
| 损耗(W) | 空载/负载 | 225/750 |
| 阻抗(%) | — | <2.5 |
| 相数 | 单相/三相 | single_phase |
| 材质 | 全铝/全铜 | aluminum |
| 油箱类型 | 普通/不锈钢/波纹 | normal |

每个字段有**颜色标记**（见§5字段颜色体系），表示当前确认状态。

**右侧——风险与动作区：**

| 区域 | 内容 |
|:----|:-----|
| 缺失字段 | 客户需求中未提供但必填的字段列表 |
| 冲突字段 | 客户需求中存在矛盾或与历史邮件冲突的字段 |
| 高风险字段 | 标记为高风险的特殊表达（如"终端型""带CSP"等） |
| 澄清问题 | 自动生成的需要向客户确认的问题列表 |
| 技术确认 | 需要技术工程师确认的关键工程字段 |
| 参数包状态 | 当前是否可以导出参数包（绿色=可导出 / 红色=阻断中） |

### 4.3 字段确认抽屉

点击中间参数区的任意字段，弹出**字段详情抽屉**，显示：

| 信息 | 说明 |
|:----|:-----|
| 标准字段名 | 系统中的标准化字段名称 |
| AI解析值 | 系统自动提取的值 |
| 原文值 | 客户原始文件中的原文表述 |
| 来源文件 | 该字段来自哪个文件 |
| 来源位置 | 原文中的具体位置（行/页码） |
| 置信度 | 0-1之间的数值，越高越可信 |
| 风险等级 | 高/中/低 |
| 确认状态 | 待确认/已确认/继承 |
| 修改历史 | 所有修改操作记录（可追溯） |
| 确认按钮 | 点击确认该字段 |

### 4.4 参数包导出页

确认完成后，进入参数包导出页，支持：

- **预览**：导出前在线预览参数包内容
- **导出**：选择格式导出
- **发送**：直接发送给指定接收人（飞书/邮件）

## 5. 字段状态与风险颜色体系

### 5.1 字段颜色含义

| 颜色 | 含义 | 需要做什么 |
|:----|:-----|:-----------|
| 🟢 **绿色** | 已确认 | 无需操作，已通过审核 |
| 🟡 **黄色** | 待确认 | 点击查看详情，确认后变绿 |
| 🔴 **红色** | 缺失、冲突、阻断 | **必须解决后才能继续**，点击查看原因 |
| 🔵 **蓝色** | 继承自项目级参数 | 系统自动带入，确认是否适用于本产品行 |
| ⚪ **灰色** | 系统默认值 | 客户未提供，系统按行业默认值填充，建议确认是否适用 |

### 5.2 高风险表达规则

以下特殊表达系统会自动标记为高风险，需要人工特别关注：

| 表达 | 系统处理方式 |
|:----|:------------|
| "无损耗" | 标记为"客户未提供损耗"，**不得填0** |
| "225/750" | 在损耗上下文中自动解析为空载/负载损耗 |
| "13200/7200-120/240V" | 保留原文，拆分需技术确认 |
| "±2×2.5%" | 标记为分接范围，不等同五档分接 |
| "全铝/全铜" | 默认绕组材料，但需销售/技术确认 |
| "终端型" | 标记为结构字段，高风险 |
| "带CSP" | 标记为关键附件，影响BOM |

### 5.3 阻断规则

**以下情况不允许生成正式参数包：**

1. ❌ 容量缺失
2. ❌ 高低压缺失
3. ❌ 相数不确定
4. ❌ 损耗字段冲突
5. ❌ 阻抗字段冲突
6. ❌ 关键字段未技术确认
7. ❌ 客户要求和历史邮件更新内容冲突

> 系统会在右侧风险区明确提示阻断原因，并标记哪些字段需要优先处理。

## 6. 典型业务场景操作指南

### 场景1：单相变压器多方案报价

**客户需求示例：**
- 75kVA，13200/7200-120/240V，60Hz，全铝
- 带CSP，普通油箱400台，不锈钢油箱100台
- 损耗225/750和165/600，阻抗<2.5%

**操作步骤：**
1. 新建项目，上传需求文件（或粘贴邮件）
2. 系统自动解析，生成4个产品行（普通油箱×2种损耗 + 不锈钢油箱×2种损耗）
3. 核对每个产品行的参数是否正确
4. 阻抗<2.5%自动标记为关键字段，需技术确认
5. 确认后导出参数包

### 场景2：三相变压器批量报价

**客户需求示例：**
- 50kVA×89台，100kVA×11台，200kVA×2台，300kVA×60台，1250kVA×10台
- 公共参数：11/0.415kV，全铜，Dyn11，ONAN

**操作步骤：**
1. 上传需求文件
2. 系统自动生成5个产品行，公共参数自动继承
3. 检查公共参数（电压、材质、联结组别等）是否正确继承
4. 按需调整各产品行的个性化参数
5. 导出参数包

### 场景3：招标文件型需求

**客户文档内容：**
- 项目级：IEC标准，苏丹户外环境，50°C，90%湿度，防腐，热带化
- 产品行：12个型号，各有不同的容量和电压

**操作步骤：**
1. 上传招标Word文档
2. 系统自动分离项目级参数和产品行参数
3. 项目级参数自动应用到所有产品行
4. 逐一确认12个产品行的参数
5. 标记500/1000kVA为"按S9待确认"
6. 导出参数包

## 7. 常见问题与注意事项

### 7.1 常见问题

**Q: AI解析的结果不准怎么办？**
A: 所有AI输出都标注了置信度和原文来源。您可以在字段确认抽屉中直接修改，修改即标注，系统会学习您的修正，下次解析更准。

**Q: 可以同时处理多个报价项目吗？**
A: 可以。报价项目列表支持多项目并行，每个项目独立流转，互不干扰。

**Q: 参数包导出后如何发送给技术部门？**
A: 导出后可通过飞书或邮件直接发送。建议使用Excel格式，法拉迪电磁计算引擎支持一键导入。

**Q: 系统会自动生成正式报价吗？**
A: 第一阶段不自动生成正式报价，只生成计算单参数包。正式报价需经过完整的匹配→成本→审批流程（第二至四阶段）。

### 7.2 使用建议

| 建议 | 说明 |
|:----|:-----|
| **上传原文优先** | 上传原始文件比手动录入更准确，系统保留原文可追溯 |
| **关注颜色标记** | 红色字段必须优先处理，黄色字段尽快确认 |
| **善用澄清问题** | 系统自动生成的澄清问题可以直接复制发送，节省沟通时间 |
| **保留邮件链** | 客户后续邮件更新内容，系统会自动与当前项目关联，检测是否冲突 |
| **知识越用越准** | 每次修改和确认都在沉淀为经验，使用越久系统越智能 |

### 7.3 系统要求

- **浏览器**：Chrome 90+ / Edge 90+
- **网络**：需连接公司内网或VPN（系统部署在法拉迪内网）
- **文件格式**：支持.docx/.jpg/.png/.pdf/.xlsx
- **单文件大小**：不超过50MB
