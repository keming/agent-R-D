## 二、技术创新目标（限500字）

　　聚焦变压器行业智能报价与设计决策数字化转型需求，以AI智能体（AI Agent）、工业大模型、行业知识图谱、多Agent协同决策等关键技术为核心，按五阶段产品设计架构（需求解析与参数包智能体→计算单匹配与设计协同智能体→BOM成本与多方案报价智能体→正式报价审批与客户文件智能体→知识沉淀与持续优化智能体），将项目拆分为三个子项目协同推进，构建覆盖客户需求解析、方案智能匹配、参数优化、电磁设计、BOM自动生成、智能成本核算、报价审批及知识沉淀的AI全流程智能报价平台。

**具体目标：**

1. **子项目A**（第一阶段，80万）：研发多Agent报价决策与HITL参数解析系统，覆盖需求解析→方案匹配→参数优化→BOM拆解→成本核算→报价输出全链路，将客制化变压器报价响应时间从7-15天压缩至≤30分钟。
2. **子项目B**（第二、三、四阶段，100万）：研发计算单匹配、BOM成本与报价审批系统，实现历史计算单A/B/C/D四级复用、BOM成本自动测算与多方案对比、四级审批流全线上化，审批效率提升≥70%。
3. **子项目C**（第五阶段，20万）：研发全链路知识库与知识沉淀持续优化系统，构建"历史方案—电磁计算数据—BOM结构—报价单—成交结果—决策原因"六维知识图谱（≥2000案例），实现每次报价数据自动回流沉淀，形成越用越准的知识飞轮效应。

　　**成果指标：** 申请发明专利≥2件，软件著作权≥3件，参与制定团体标准≥1项，发表高水平论文≥1篇。项目执行期内实现新增产值≥1500万元，新增利润≥200万元。

## 四、温州市创新联合体攻关项目

### 4.1 项目设计

#### 4.1.1 总体设计

　　本创新联合体聚焦变压器报价与设计决策环节×AI多Agent技术赋能，依据产品设计五阶段架构，按技术关联度拆分为三个子项目协同推进：

| 子项目 | 名称 | 覆盖阶段 | 总经费 | 承担单位 |
|:------:|:----|:--------:|:------:|---------|
| 子项目A | 多Agent报价决策与HITL参数解析系统 | 第一阶段 | 80万 | 轨物科技（主承担）+ 法拉迪 + 杭电 |
| 子项目B | 计算单匹配、BOM成本与报价审批系统 | 第二、三、四阶段 | 100万 | 法拉迪（主承担）+ 杭电 + 轨物科技 |
| 子项目C | 全链路知识库与知识沉淀持续优化系统 | 第五阶段 | 20万 | 杭电（主承担）+ 法拉迪 + 轨物科技 |
| **合计** | | **全五阶段** | **200万** | |

　　三个子项目形成"报价→匹配→成本→审批→沉淀→优化"的数据闭环：子项目A产出的标准参数包→子项目B的计算单匹配和BOM成本计算→子项目C的知识沉淀与持续优化；子项目C的反向数据流（历史案例、成交规律、优化规则）反哺给子项目A和B。

#### 4.1.2 项目设计的必要性（限1000字）

**（一）产业刚需驱动**

　　变压器是电力系统最核心的基础设备之一，年产值超过1500亿元。温州作为全国电气装备制造产业集群核心区域，已形成以正泰、天正、法拉迪等骨干企业为代表的完整产业链。当前温州变压器产业在销售与报价环节面临突出瓶颈：从客户需求到输出报价平均需要7-15个工作日，丢单率高达15-30%。报价环节高度依赖资深工程师的个人经验，培养周期长达3-5年，已成为制约行业竞争力的关键瓶颈。报价慢的问题不仅影响销售端，更造成全流程的效率损失。

**（二）技术变革窗口**

　　人工智能（尤其是大语言模型和多Agent系统）、知识图谱、向量检索等技术的快速发展，为传统变压器报价的数字化转型提供了成熟条件。国内在变压器数字化方向已有一定积累，但报价端仍以"工程师人工评审+Excel核算"为主流模式，尚未出现面向变压器领域的成熟AI报价产品。多Agent协同报价决策技术——通过多个专业Agent分工协作实现需求解析→方案匹配→参数优化→BOM→成本→报价→审批→沉淀的全链路智能化——为系统解决这一行业痛点提供了全新的技术路径。

**（三）政策高度契合**

　　本项目属于温州市"5+5+N"重点产业链中的电气产业链细分领域，由浙江法拉迪电气股份有限公司牵头，联合杭州电子科技大学、浙江天正电气股份有限公司、杭州轨物科技有限公司、乐清市雁荡山电气研究院、温州赛宝工业技术研究院、乐清市变压器协会、浙江凯变电气有限公司、杰豪电气科技有限公司等9家单位组建，符合"成员不少于6个、温州本地单位不低于50%、企业不低于50%"的申报要求。聚焦前沿技术赋能传统产业，形成产品化、场景化的标志性成果。

#### 4.1.3 目标体系（限1000字）

**主目标：**

　　用3年时间，建成以法拉迪为核心的变压器AI智能报价与设计决策技术创新联合体，完成三个子项目的技术攻关与产业化应用，形成可复制、可推广的"AI+变压器全流程报价"解决方案，带动温州变压器产业链报价环节的数字化水平提升。

**分项目目标：**

- **子项目A**（80万，轨物主承担）：研发多Agent报价决策与HITL参数解析系统，实现从客户需求上传到报价草稿的≤30分钟全链路自动化，HITL字段溯源覆盖率100%，七条阻断规则自动校验。
- **子项目B**（100万，法拉迪主承担）：研发计算单匹配、BOM成本与报价审批系统，A/B/C/D四级复用匹配准确率≥85%，BOM成本计算准确率≥95%，审批效率提升≥70%。
- **子项目C**（20万，杭电主承担）：研发全链路知识库与知识沉淀持续优化系统，六维知识图谱≥2000案例，知识沉淀自动回流覆盖率100%，字段字典与同义词库每月自动优化。

### 4.2 技术路线图

　　本项目采用"场景驱动、数据闭环、增量迭代"的研究范式。以多Agent协同报价决策为核心，子项目A为数据入口和业务起点，客户询价文件经多模态需求解析Agent提取结构化参数，通过向量+图混合检索从全链路知识库匹配历史方案，再由参数优化Agent驱动法拉迪电磁计算引擎做增量优化，依次经BOM拆解Agent、成本核算Agent、报价输出Agent完成报价草稿。子项目B接收子项目A产出的标准参数包，完成计算单A/B/C/D四级复用匹配、BOM成本测算、多方案比价，经四级审批流输出正式报价单和客户文件包。子项目C贯穿始终，每一次报价数据自动回流至六维知识图谱，形成知识飞轮效应。

　　涉及8项核心技术：K1多Agent协同报价与HITL决策（子A）、K2智能定价优化与库存联动（子B）、K3 LLM+知识图谱知识工程化（子A/C）、K4计算单A/B/C/D四级复用（子B）、K5工程参数约束推理与阻断规则（子A）、K6电磁计算引擎智能参数推荐（子C）、K7多源价格数据融合与BOM分析（子B）、K8知识飞轮与自优化学习（子C）。其中K6对接法拉迪已有电磁计算引擎和SolidWorks参数化出图系统，实现报价→计算→设计报告→图纸的全链路交付。

### 5.2 主要研发内容及创新点/关键技术（限1000字）

**研发内容：**

　　本项目按技术关联度拆分为三个子项目：

**子项目A——多Agent报价决策与HITL参数解析系统（第一阶段，80万）。** 研发六大专业Agent在统一Agent Runtime上的分工协作体系（需求解析Agent→方案匹配Agent→参数优化Agent→BOM拆解Agent→成本核算Agent→报价输出Agent）。构建HITL字段溯源与阻断规则体系，每个解析字段记录置信度、原文来源、风险等级，以绿/黄/红/蓝/灰五色标记状态，七条阻断规则嵌入Agent工作流。研发OCR+LLM解析管线，支持招标文件"项目级参数"与"产品行参数"自动分离和继承。研发6个核心前端页面（项目列表、需求输入、三栏解析工作台、字段确认抽屉、澄清问题、参数包导出）。

**子项目B——计算单匹配、BOM成本与报价审批系统（第二、三、四阶段，100万）。** 建立历史计算单索引，基于参数相似度+工程约束匹配输出A/B/C/D四级复用等级，展示差异项分析报告。BOM导入→物料价格匹配（实时价格接口+网上行情）→价格有效期检查→成本测算→多方案成本对比→报价草稿生成。支持智能定价策略引擎（抢单/利润/清库存三种模式，联动ERP库存）。四级审批流、报价版本管理、客户文件包自动生成（含报价单+技术方案+设计图纸）。

**子项目C——全链路知识库与知识沉淀持续优化系统（第五阶段，20万）。** 构建"历史方案—电磁计算数据—BOM结构—报价单—成交结果—决策原因"六维知识图谱，每次报价数据自动回流沉淀。形成字段字典迭代表、规则优化记录、历史报价看板、计算单复用看板、销售问答模板库。电磁计算引擎参数推荐系统（22维特征→5维关键参数，搜索空间缩小60-90%）和SolidWorks参数化出图联动。

**关键技术：**

| 编号 | 关键技术 | 所属子项目 |
|:----:|---------|:---------:|
| K1 | 面向变压器领域的多Agent协同报价 | A |
| K2 | 面向定制化产品的智能定价优化与库存联动技术 | B |
| K3 | 基于LLM+知识图谱的变压器领域知识工程化技术 | A/C |
| K4 | 计算单A/B/C/D四级复用与差异分析技术 | B |
| K5 | 工程参数约束推理与报价阻断规则技术 | A |
| K6 | 电磁计算引擎智能参数推荐与搜索空间优化技术 | C |
| K7 | 多源价格数据融合与BOM智能分析技术 | B |
| K8 | 知识飞轮与自优化学习技术 | C |

**创新点：**

1. **行业首创面向变压器领域的多Agent全流程报价决策体系**：通过三个子项目系统化分工协作，覆盖报价全生命周期，替代传统7-15天人工流程。
2. **六维全链路知识图谱驱动的知识飞轮与持续优化机制**：每次报价数据自动回流沉淀，形成越用越准的知识飞轮效应。
3. **计算单A/B/C/D四级复用与差异分析技术**：首创面向变压器领域的计算单复用等级体系，结合差异项可解释性报告，实现历史工程知识的精准复用。
4. **计算引擎智能推荐、SolidWorks出图与报价参数联动优化**：搜索空间缩小60-90%，实现报价→计算→设计报告→图纸的全链路交付。

### 5.6 知识产权归属、成果管理及合作权益分配（限1500字）

**基本原则：** "共同创造、共享收益、事先约定、纠纷调解"。

**知识产权归属：**

| 情形 | 知识产权归属 | 权益分配 |
|------|------------|---------|
| 单一成员独立完成 | 归该成员所有 | 自主处置 |
| 轨物科技与法拉迪共同完成（Agent架构和业务规则的联合开发成果） | 共同所有 | 按实际贡献比例协商确定，轨物享有软件著作权，法拉迪享有在自身业务中的优先使用权 |
| 利用联合体公共经费委托开发 | 委托方和承接方共同所有 | 按委托合同约定分配 |

**产业化收益分配：**
- **法拉迪**：优先获得面向自身变压器生产场景的无偿使用权，对外技术服务时按约定分成
- **轨物科技**：主导系统的商业化推广（SaaS订阅/私有化部署），法拉迪享有推广收益的协商分成权

**成果管理：**
- 设立知识产权与成果管理组，专利申请前置评审制度（提前30天通知）
- 软件著作权由轨物科技负责申请，发明专利申请依贡献方协商确定发明人排序

**退出机制：**
- 成员退出需提前3个月书面通知理事会
- 联合体解散时，已形成的知识产权按上述归属原则处理
