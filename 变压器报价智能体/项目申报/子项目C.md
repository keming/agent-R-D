# 子项目C：全链路知识库与知识沉淀持续优化系统

**总经费**：20万元 | **覆盖阶段**：第五阶段（知识沉淀与持续优化智能体）| **主承担单位**：杭州电子科技大学

---

## 1. 主要研发内容及创新点/关键技术（不超过1000字）

### 研发内容

覆盖产品设计第五阶段——**知识沉淀与持续优化智能体**，让系统越用越准。

**（1）六维全链路知识图谱**：构建"历史方案—电磁计算数据—BOM结构—报价单—成交结果—决策原因"六维知识图谱，采用向量数据库+图数据库混合存储，目标规模2000+全链路案例。

**（2）知识飞轮与自优化机制**：每一笔报价完成后，客户原文、AI解析结果、人工修正记录、技术确认日志、成交/丢单结果、决策原因全部自动回流至知识库。系统随运行时间积累更多案例，方案匹配精度持续提升，字段字典和同义词库自动优化。

**（3）历史报价分析与预警**：沉淀样例、规则、历史报价、常见问题，形成字段字典迭代表、规则优化记录、历史报价看板、计算单复用看板、销售问答模板库。异常报价自动预警（如利润率异常偏低、价格有效期即将过期等）。

**（4）电磁计算引擎智能优化与出图联动**（跨子项目支撑）：对接法拉迪已有电磁计算引擎和参数推荐系统。研发22维特征→5维关键参数（CRGOD/LVT/LVRH/HVRH/CT）的智能推荐，基于方差归约权重从历史成功方案中学习最优搜索范围，使计算搜索空间缩小60-90%。对接法拉迪已有SolidWorks参数化出图系统（单相工程图+三相三维油箱），实现报价方案→设计报告→图纸的全链路交付。

### 关键技术

| 编号 | 关键技术 | 技术难点 |
|:----:|---------|---------|
| K3 | **基于LLM+知识图谱的变压器领域知识工程化技术** | 非标口语化表达到标准化工程参数的准确映射；多源异构知识的结构化融合；报价阻断规则的工程化建模 |
| K6 | **电磁计算引擎智能参数推荐与搜索空间优化技术** | 22维输入特征与5维输出参数的非线性映射建模，方差归约权重可靠性保障，冷启动推荐策略 |
| K8 | **知识飞轮与自优化学习技术** | 报价全链路数据自动回流，字段字典和同义词库的增量更新，异常报价自动预警模型的构建 |

### 创新点

1. **六维全链路知识图谱驱动的知识飞轮与持续优化机制**：构建"历史方案—电磁计算数据—BOM结构—报价单—成交结果—决策原因"六维知识图谱，每次报价的客户原文、解析结果、人工修正、成交反馈全部自动回流沉淀。将AI报价系统从"单次工具"升级为"越用越准的持续优化平台"，形成自我增强的知识飞轮效应。
2. **计算引擎智能推荐、SolidWorks出图与报价参数联动优化**：将报价Agent解析出的方案参数自动反馈至电磁计算引擎的参数推荐系统和SolidWorks出图系统，实现报价→计算→设计报告→图纸的全链路交付，计算搜索空间缩小60-90%。

## 2. 研发目标及主要技术经济指标

### 2.1 研发目标（限1500字）

研发一套全链路知识库与知识沉淀持续优化系统，具体包括：
1. **六维知识图谱**：向量数据库+图数据库混合存储，≥2000个全链路案例
2. **知识飞轮机制**：每次报价数据自动回流，方案匹配精度持续提升，字段字典和同义词库自动优化
3. **历史报价分析与预警**：字段字典迭代表、规则优化记录、历史报价看板、计算单复用看板
4. **电磁计算引擎参数推荐系统**：22维特征→5维关键参数，搜索空间缩小60-90%
5. **SolidWorks参数化出图联动**：单相工程图+三相三维油箱自动生成

**预期成果形式**：知识库管理系统1套（含向量数据库、图数据库、数据回流管线、参数推荐系统）。

### 2.2 约束性指标

| 指标 | 目标值 |
|------|--------|
| 案例知识库规模 | ≥2000个全链路案例 |
| 知识沉淀自动回流覆盖率 | 100%（每次报价数据自动入库） |
| 电磁计算引擎搜索空间缩减率 | ≥60%（通过参数推荐系统） |
| 字段字典与同义词库自动优化 | 每月至少一次增量更新 |

**量化指标：**
1. 解决关键共性技术3项，具体为基于LLM+知识图谱的知识工程化技术、电磁计算引擎智能参数推荐技术、知识飞轮自优化学习技术。

### 2.3 预期性指标

**基础理论成果：**
- 发表高水平论文1篇。

**其他预期性成果：**
- 引育博士或硕士研究生2名。
