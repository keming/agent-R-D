# Faladi 变压器优化设计系统 — 使用说明书

> 版本：v1.0 | 2026-06-30

---

## 一、产品简介

Faladi 是变压器电磁方案自动寻优系统，支持单相柱上变和三相油浸配变。输入性能要求和工艺参数后，系统自动在成千上万种组合中找出满足指标且成本最低的方案，并可一键导出设计报告、驱动 SolidWorks 生成加工图纸。

**主要功能：**
- 电磁方案自动寻优（单相 / 三相）
- 计算结果合规判定（严格合规 / 近似合规）
- 设计报告导出（Excel）
- SolidWorks 参数化 2D / 3D 出图

## 三、方案配置

方案配置通过**四步向导**完成：

```
性能指标 → 优化范围 → 工艺指标 → 开始计算
```

其中「工艺指标」页内含 4 个子页签：**铁芯 → 线圈 → 绝缘 → 油箱及单价**。

---

### 第一步：性能指标

定义产品的电气规格和验收标准，计算结束后用来**判定方案是否合格**。

| 参数 | 作用 |
|---|---|
| 容量（kVA） | 产品规格，参与铁心截面、电流、损耗等全部后续计算 |
| 频率（50/60Hz） | 影响磁通密度和铁损计算，切换后自动设定折算温度 |
| 空载损耗 + 偏差（W/%） | 铁心损耗的验收标准，最终判定用 |
| 负载损耗 + 偏差（W/%） | 绕组损耗的验收标准，最终判定用 |
| 阻抗电压 + 正负偏差（%） | 短路阻抗的验收标准，最终判定用 |
| 高压 / 分接 / 低压（V） | 电压组合，决定匝数比和绝缘等级 |
| 绕法 + 联结组别（三相） | 常规 / 高压分段 / 低高压双分，决定绕组结构 |
| 段间距（三相分段时） | 分段绕组之间的绝缘间距 |
| 空载 / 负载 / 阻抗的上下限 | 缩小验收窗口。算出的损耗低于下限或高于上限都会被淘汰 |
| 负载损耗系数 | 引线损耗等附加损耗的折算系数，参与损耗计算 |
| 阻抗系数 | 电抗计算修正系数，可自动也可手动 |
| 负载折算温度（℃） | 电阻折算到参考温度的值 |

---

### 第二步：优化范围

设定各参数的搜索边界。**这些参数是控制计算量的关键**——超出边界的组合会在循环中途被直接丢弃，不再继续往下算。

| 参数 | 作用 |
|---|---|
| 铁心片宽下限/上限（mm，单相） | 控制铁心搜索范围，超限立即跳过当前组合 |
| 铁心叠厚下限/上限（mm，单相） | 同上，与片宽共同决定铁心截面 |
| 铁心直径下限/上限（mm，三相） | 控制铁心搜索范围，超限立即跳过。是最关键的筛选条件——直径决定了磁通密度，磁通密度又决定了损耗 |
| 低压匝数下限/上限 | 控制匝数搜索范围，超限跳过。改动匝数会连锁影响磁密、损耗、阻抗 |
| 磁通密度下限/上限（T） | **最早触发的短路条件**。磁密由铁心截面和匝数决定，一旦算出不在范围内，后续的线规、层数、温升全部跳过 |
| 绕组温升限制（K） | 最终判定用，任意线圈温升超过此值即淘汰 |
| 油顶层温升限制（K） | 最终判定用 |
| 铜电流密度下限/上限（A/mm²） | 铜线方案的电流密度必须在范围内，超限淘汰 |
| 铝电流密度下限/上限（A/mm²） | 铝线方案的电流密度必须在范围内，超限淘汰 |

---

### 第三步：工艺指标

**铁芯：**

| 参数 | 作用 |
|---|---|
| 硅钢片牌号（多选） | 决定了铁损特性和可用磁密范围。每种牌号的损耗曲线不同，直接影响空载损耗。多选即遍历 |
| 铁芯形式 | 单相：卷铁芯/折铁芯；三相：圆形/长圆形/椭圆形。不同形式查不同的截面数据库 |
| 工艺系数 | 铁心制造工艺附加损耗系数 |
| 叠片系数 | 硅钢片叠装紧密程度，影响有效截面 |

**高压线圈：**

| 参数 | 作用 |
|---|---|
| 线规 | 铜/铝 + 圆线/扁线的选择，决定用哪个数据字典查线规截面 |
| 油道数量 + 类型（三相多选） | 每个选项都是一个独立的搜索分支。数量和类型越多，计算量成倍增加 |
| 油道厚度（mm） | 参与绕组辐向尺寸和散热面积计算 |
| 导线绝缘厚度（mm） | 扁线线规时参与尺寸计算，圆线时系统自动设为默认值 |
| 轴向/辐向并绕 | 多根并绕相当于增大截面，可降低电流密度 |
| 轴向绕制系数 | 绕线时的松紧程度，影响绕线高度 |
| 辐向绕制系数 | 影响辐向厚度 |
| 扁线厚/宽/宽厚比限制 | **短路条件**：扁线线规时，线规截面不在限制范围内会直接跳过当前组合 |
| 散热系数（三相） | 内表面/外表面/半油道/全油道，参与线圈温升计算 |
| 最小/最大高度（mm） | **短路条件**：绕线高度超出此范围直接跳过 |
| 最小/最大层数 | **短路条件**：层数不在范围内跳过，或匝数无法等分时跳过 |

**低压线圈：**

| 参数 | 作用 |
|---|---|
| 线规 | 箔绕（LM铝箔/TM铜箔）或线绕（ZLB纸包扁铝/ZB纸包扁铜）。箔绕截面 = 宽 × 厚直接算，线绕需查扁线表并校验宽厚比。Yz 联结只支持线绕 |
| 油道数量 + 类型（三相多选） | 同高压，每个选项一个搜索分支 |
| 油道厚度（mm） | 参与辐向尺寸和散热面积计算 |
| 导线绝缘厚度（mm） | 线绕时可编辑，箔绕时系统自动锁定为 0 |
| 轴向/辐向并绕 | 多根并绕增大等效截面，降低电流密度。仅三相时可编辑 |
| 轴向绕制系数 | 影响绕线高度，仅三相时可编辑 |
| 辐向绕制系数 | 影响辐向厚度，仅三相时可编辑 |
| 低压层间厚（mm，单相） | 箔绕时系统自动根据厚度判定 |
| 扁线厚/宽/宽厚比限制 | **短路条件**：线绕时截面不在限制范围内直接跳过 |
| 散热系数（三相） | 内表面（排散热）/外表面（主空道）/半油道/全油道，参与温升计算 |
| 最小/最大高度（mm） | **短路条件**：绕线高度超出范围直接跳过；同时参与高低压高度差校验 |
| 最小/最大层数（单相） | **短路条件**：层数不在范围内或匝数不能等分时跳过 |

**绝缘：**

| 参数 | 作用 |
|---|---|
| 电压等级 | 10kV/20kV/35kV，切换后各绝缘距离自动填入推荐默认值 |
| 铁心到低压距离 | 内层起始距离。三相时还会根据低压线规自动联动：箔绕默认 5~6mm，线绕默认 3.5mm |
| 低高主空道 | 低压和高压之间的主绝缘距离，影响阻抗 |
| 高低主空道（单相） | 内外线圈之间的绝缘距离 |
| 相间距（三相） | 三相绕组之间的间距，影响油箱尺寸 |
| 低压到铁轭距离 | 绕组下端绝缘，**短路条件**：距离不足时跳过 |
| 高压到铁轭距离 | 绕组上端绝缘，**短路条件**：距离不足时跳过 |
| C 型板厚（单相） | 铁心夹件厚度 |

**油箱：**

单相：

| 参数 | 作用 |
|---|---|
| 器身到箱盖距离 | 油箱顶部空间，影响油箱高度和油重 |
| 器身对角间距 | 线圈对角方向到箱壁的距离 |
| 器身前后间距 | 线圈前后方向到箱壁的距离 |
| 空气层高度 | 油面以上空气层高度，参与散热计算 |

三相：

| 参数 | 作用 |
|---|---|
| 油箱类型 | 波纹翅片 / 散热片，不同类型油箱散热面积算法不同 |
| 防腐等级 | C3/C4/C5，切换自动联动油箱基价（14.5/15.5/16.5） |
| 油箱长/宽/高空隙 | 器身到油箱内壁的三个方向距离 |
| 空气层高度 | 油面以上空气层 |
| 长轴波纹面数 | 0/1/2，影响波纹散热面积和油箱尺寸 |
| 短轴波纹面数 | 0/1/2，影响波纹散热面积和油箱尺寸 |
| 储油柜 | 是否带储油柜，影响膨胀容积和油箱成本 |
| 散热器片宽（散热片时） | 310/480/520，不同片宽的散热面积和自重不同 |
| 散热器组数范围（散热片时） | min~max，设定后系统自动寻优最佳组数 |
| 箱壁厚 / 箱底厚 / 箱盖厚 | 油箱结构尺寸，影响油箱重量 |
| 箱沿 / 角钢 / 底盖 / 垫脚 | 油箱结构附件尺寸，影响油箱重量 |
| [获取推荐值] 按钮 | 系统根据容量、短轴波纹数、高压电压自动计算并填入上述油箱重量参数 |

> 三相油箱中波纹油箱还需校验**油膨胀量是否超过波纹容纳能力**——这也是一个短路条件，膨胀不满足时直接淘汰当前油箱组合。

**材料单价：** 所有单价均为元/KG。显示项根据铁芯页面所选牌号和线圈页面所选线规**动态过滤**，只出现当前方案用到的材料，避免无关字段干扰。

## 四、方案计算

### 计算原理

保存方案后点击「计算」，系统在后台自动穷举所有可能的参数组合，对每种组合执行完整的电磁计算（铁心→绕组→绝缘→阻抗→温升→油箱→成本），选出**性能合规且价格最低**的方案。

搜索顺序大致为：硅钢片牌号 → 低压匝数 → 铁心直径 → 低压线规 → 低压层数 → 高压线规 → 高压层数 → 油箱。

### 搜索效率

用户在前三步中填写的**范围类参数**，在计算过程中直接充当短路条件——一旦某层算出的值不在范围内，该分支后续所有循环全部跳过。主要短路点与参数的对应关系：

| 短路条件 | 由哪个参数控制 | 触发位置 |
|---|---|---|
| 铁心直径查不到截面数据 | 铁芯形式（圆形/长圆形/椭圆形各自查不同表） | 铁心层 |
| 磁通密度低于下限 | 第二步「磁通密度下限」 | 铁心层 |
| 磁通密度高于上限 | 第二步「磁通密度上限」 | 铁心层 |
| 硅钢片损耗表无对应磁密的数据 | 硅钢片牌号本身决定的损耗曲线范围 | 铁心层 |
| 低压扁线宽厚比不合规 | 第三步低压线圈「扁线宽厚比限制」 | 低压线规层 |
| 低压线规截面查不到 | 数据字典扁线/箔材表范围 | 低压线规层 |
| 低压扁线宽/厚不在限制范围 | 第三步低压线圈「扁线厚/宽限制」 | 低压线规层 |
| 低压层数不在范围或匝数不能等分 | 第三步低压线圈「最小/最大层数」 | 低压层数层 |
| 高压扁线宽厚比不合规 | 第三步高压线圈「扁线宽厚比限制」 | 高压线规层 |
| 高压线规截面查不到 | 数据字典扁线/圆线表范围 | 高压线规层 |
| 高压扁线宽/厚不在限制范围 | 第三步高压线圈「扁线厚/宽限制」 | 高压线规层 |
| 高压圆线线径不匹配 | 数据字典圆线表范围 | 高压线规层 |
| 高压层数不在范围或匝数不能等分 | 第三步高压线圈「最小/最大层数」 | 高压层数层 |
| 低压电流密度超限 | 第二步「铜/铝电流密度上下限」（根据线规材质判定） | 高压层数层 |
| 高压电流密度超限 | 第二步「铜/铝电流密度上下限」（圆线/扁线分别判定） | 高压层数层 |
| 低压绕线高度不在范围 | 第三步低压线圈「最小/最大高度」 | 高压层数层 |
| 高压绕线高度不在范围 | 第三步高压线圈「最小/最大高度」 | 高压层数层 |
| 端部绝缘距离不足 | 第三步绝缘「到铁轭距离」 | 高压层数层 |
| 波纹油箱膨胀不满足 | 油箱尺寸（油膨胀量超过波纹容纳能力） | 油箱层 |
| 空载损耗不合格 | 第一步「空载标准 + 上下限」 | 最终判定 |
| 负载损耗不合格 | 第一步「负载标准 + 上下限」 | 最终判定 |
| 阻抗不合格 | 第一步「阻抗标准 + 上下限」 | 最终判定 |
| 油顶温升不合格 | 第二步「油顶层温升限制」 | 最终判定 |
| 各线圈温升不合格 | 第二步「绕组温升限制」 | 最终判定 |

> 短路出现越早，跳过的内层循环就越多。磁通密度在最早阶段短路，效率最高；最终判定（损耗/阻抗/温升）已是计算完所有参数后，只能淘汰不能提前跳层。因此缩小磁密、高度、层数这些嵌套较浅的参数范围，对加速计算最有效。

> 范围设得越窄，短路触发越早，计算越快。但过窄可能找不到任何合格方案。

### 计算过程

1. 点击「计算」→ 系统异步启动
2. 页面每 3 秒刷新进度（已完成数 / 总数 + 耗时 + 合格方案数）
3. 可随时点击「终止计算」
4. 完成后自动展示结果

### 合规判定

| 级别 | 含义 |
|---|---|
| **严格合规** | 所有性能指标满足原始标准 |
| **近似合规** | 无严格方案时，标准放宽 15%（温升 +10K）后满足 |

择优规则：同批次中取价格最低者。

### 结果查看

点击方案记录可查看详细计算结果，涵盖铁心、高低压绕组、阻抗、温升、油箱、成本等 200+ 项参数。

## 五、结果导出

## 六、参数化出图（单相）

根据计算结果驱动 SolidWorks 自动生成二维工程图纸。

**操作流程：**
1. 上传 Excel 参数文件
2. 选择模板类型（1~64 种）、设置电压/电流/伞裙/安装方式等
3. 系统调用 SolidWorks 生成图纸，进度实时反馈
4. 下载 ZIP 图纸包

## 七、三维油箱设计（三相）

根据三相变压器参数驱动 SolidWorks 生成油箱三维模型和外形图。

**支持功能：**
- 油箱三维装配体参数驱动
- 油箱外形工程图（法标 H61 等）
- 高低压套管自动替换
- 多种油箱类型：波纹片 / 散热片、不同波纹数组合

## 十、典型操作流程

```
① 选择变压器类型（单相 / 三相）
        ↓
② 新建方案 → 四步向导填写参数 → 保存
        ↓
```
