### 3.1 价值主张画布（Value Proposition Canvas）

| 维度 | 内容 |
|------|------|
| **Who（目标用户）** | 变压器制造企业的**销售/商务人员**（一线用户）和技术负责人（审核用户）。销售直接面对客户，需要快速响应询价；技术负责人负责方案把关和最终审批 |
| **Why（核心痛点）** | ① 报价响应慢（7-15天），客户同时询价 3-5 家，丢单率 15-30%；② 销售不懂技术参数，依赖技术部门"翻译"客户需求；③ 技术人员 40-60% 时间消耗在重复性报价工作上；④ 历史方案复用靠人脑记忆，经常找不到或找不准；⑤ 新人上手需 6-12 个月，知识随人员流失 |
| **What Before（现有替代方案）** | ① Excel 手工填报价单 + 人工核算成本；② 邮件/电话反复沟通技术部确认方案；③ 翻历史文件夹找类似项目参考；④ 技术人员手动重新计算电磁参数；⑤ 审批流程走纸质或 OA 系统——每一步都耗时且依赖人 |
| **How（我们的解决方案）** | AI 驱动的报价/方案智能体：销售上传客户需求文件 → Agent 自动解析参数、匹配已完成计算的历史项目并导入数据 → 调用电磁计算引擎优化方案 → 自动拆解 BOM、核算成本 → 生成报价单 → 专家审核确认。**全程 15-30 分钟，替代 7-15 天** |
| **What After（使用后状态）** | ① 销售独立完成报价，不依赖技术部"翻译"；② 响应时间从 7-15 天缩短到 30 分钟，抢在竞争对手前面；③ 技术人员从重复报价中解放，回归研发；④ 历史方案数据自动复用，不再"找文件"；⑤ 报价一致性 100%，消除"不同人报不同价"；⑥ 新人上手周期从 6-12 个月缩短到 2-4 周 |
| **Alternatives（竞品对比）** | ① **通用 CPQ 软件**（Salesforce CPQ、配置器）：只做配置和定价，不做电磁计算优化——变压器是技术密集型产品，通用工具无法处理工程计算；② **ERP 内嵌报价模块**：只能基于现有 BOM 和固定公式报价，无法处理"从零设计"的客制化场景；③ **其他变压器厂家的内部系统**：无标准化产品，各厂自研；④ **轨物方案的差异化**：直接对接电磁计算引擎+已完成计算项目库，是唯一能覆盖"需求解析→工程计算→报价输出"全链路的方案 |

### 3.2 产品战略画布（Product Strategy — 9 部分）

#### 1. Vision（愿景）

> **让每一份变压器报价都基于工程验证，让销售 30 分钟内给出客户专业方案——从"报价靠经验"到"报价靠数据"。**

#### 2. Target Segments（客户分群）

| 分群 | 特征 | 痛点强度 | 优先级 |
|------|------|:--------:|:------:|
| **Tier 1：中小型变压器制造企业** | 年产值 5000万-5亿，5-30 人技术团队，多品种小批量定制化为主 | ★★★★★ | **P0** |
| **Tier 2：大型变压器集团** | 年产值 5亿+，有 ERP/PLM 系统，但报价流程仍依赖人工 | ★★★★ | P1（Phase 2+） |
| **Tier 3：电力装备集成商** | 自身不做变压器设计，但需要快速向终端客户报价（贸易型） | ★★★ | P2（Phase 3+） |

**首批目标客户**：法拉迪（已签约，P0 验证客户）→ 同行业同规模企业横向复制。

#### 3. Costs（成本结构）

| 成本项 | Phase 1（1-2月） | Phase 2（3-6月） | Phase 3（6-12月） |
|--------|:-----------------:|:-----------------:|:-----------------:|
| **研发人力** | 2 全职 + 法拉迪技术配合 | 2-3 全职 + 法拉迪配合 | 2 全职维护 + 自动化 |
| **LLM API 调用** | ~¥2000/月 | ~¥5000/月 | ~¥8000/月 |
| **向量数据库/存储** | ~¥500/月 | ~¥1500/月 | ~¥3000/月 |
| **部署/运维** | 复用法拉迪基础设施 | 独立部署 | 扩展部署 |
| **客户成功** | 轨物创始人亲自对接 | 1 名客户成功 | 标准化 onboarding |

**Phase 1 目标成本**：约 ¥15-20 万（人力 + API + 基础设施）。

#### 4. Value Props（核心价值）

| 价值维度 | 对销售的价值 | 对技术负责人的价值 | 对企业决策者的价值 |
|---------|------------|------------------|------------------|
| **速度** | 30 分钟出报价，抢在竞争对手前面 | 从重复报价中解放 | 报价响应快 → 丢单率降低 |
| **质量** | 报价基于工程验证数据，不会"报错" | 方案一致性 100%，风险可控 | 亏本接单概率降低 |
| **知识** | 不懂技术也能出专业报价 | 历史方案自动复用 | 知识不再随人员流失 |
| **成长** | 新人 2-4 周独立出报价 | 专家时间聚焦高价值研发 | 团队能力提升 |

#### 5. Trade-offs（取舍决策）

| 决策项 | 选择 | 放弃 | 理由 |
|--------|------|------|------|
| **覆盖面 vs 深度** | 先深后广——先做干式变压器，验证后再扩展油浸式 | Phase 1 不做油浸式全品类 | 干式变压器占法拉迪营收主体，集中火力验证 |
| **自动化 vs 准确性** | Phase 1 强制 HITL（所有报价人工确认） | 不做全自动报价 | 报价错误成本极高，必须先积累信任 |
| **标准化 vs 灵活性** | 标准化报价模板 + 少量可配置项 | 不做完全自由排版 | 80% 的报价用标准模板足够，20% 极端定制仍人工 |
| **自有平台 vs 依赖法拉迪** | 基于法拉迪 Agent 平台扩展 | 不自建独立平台 | 复用已有资产节省 60-70% 工程量 |
| **定价 vs 免费** | 项目制交付 + 年度订阅 | 不做免费试用 | B2B 制造业，免费试用反而降低信任 |

### 3.4 定价策略

#### 3.4.1 报价智能体本身的定价（卖给法拉迪的商业模式）

本产品是 **B2B SaaS + 专业服务**混合模式，向法拉迪（及后续变压器制造企业）收费。

#### 3.4.2 定价模型选择

| 模型 | 优势 | 劣势 | 适用阶段 |
|------|------|------|---------|
| **项目制交付** | 收入确定、客户决策简单 | 不利于持续收入 | Phase 1-2 |
| **年度订阅制** | 持续收入、客户粘性 | 需要产品足够成熟 | Phase 2+ |
| **按量计费** | 与使用量挂钩、公平 | 收入波动、客户难预测 | 不推荐（B2B不适合） |

**推荐策略**：Phase 1-2 采用 **项目制 + 年度维护费**，Phase 3 转向 **年度订阅制**。

#### 3.4.3 价格锚点和参考

| 定价维度 | 参考基准 | 建议定价 |
|---------|---------|---------|
| **项目制交付** | 法拉迪当前合同 Phase 1-3 已覆盖基础平台 | 报价 Agent 扩展包：**¥30-50万**（Phase 1-2 交付） |
| **年度订阅费** | 1 名技术人员年薪 ¥15-25万，报价 Agent 替代 0.5-1 人工作量 | **¥8-15万/年**（含升级维护、知识库更新） |
| **按用户数** | 不推荐单独按用户收费——变压器厂报价人员通常 3-10 人 | 包含在年度订阅中，不限用户数 |
| **增值服务** | 深度定制（油浸式适配、新行业扩展） | **¥5-10万/次** |

#### 3.4.4 定价逻辑

```
客户 ROI 计算：
  当前成本：1 名技术人员 × 50% 时间 × ¥20万/年 = ¥10万/年 纯报价成本
  + 丢单损失：年询价 200 单 × 15% 丢单率 × 平均单价 ¥10万 = ¥300万/年
  
  Agent 成本：¥10万/年（订阅费）
  Agent 价值：
    - 节省技术人员时间：¥5-10万/年
    - 降低丢单率：15% → 5%（保守估计），减少 ¥200万/年 损失
    
  ROI = (¥200万+¥5万) / ¥10万 = 20:1
```

#### 3.4.5 法拉迪特殊定价（首批客户）

| 项目 | 说明 |
|------|------|
| **首年定价** | 项目制交付 ¥30万（含 Phase 1-2 全部功能 + 部署 + 培训） |
| **年度维护** | ¥8万/年（Phase 3 功能 + 知识库更新 + 技术支持） |
| **数据要求** | 法拉迪提供 50-100 份历史项目数据（已签约配合） |
| **后续扩展** | 油浸式适配 + 新功能按 ¥5-10万/次 计费 |

### 4.1 北极星指标（North Star Metric）

#### 4.1.1 商业游戏类型判定

| 游戏类型 | 定义 | 匹配度 |
|---------|------|:------:|
| **Attention Game** | 用户注意力/使用时长 | ❌ 不匹配 |
| **Transaction Game** | 交易量/交易额 | ⚠️ 部分匹配 |
| **Productivity Game** | 帮用户完成任务的效率 | ✅ **最佳匹配** |

**判定结果**：报价智能体是典型的 **Productivity Game**——核心价值是帮销售/技术人员更快、更准地完成报价任务。

#### 4.1.2 北极星指标

> **每周完成的报价单数量**（Weekly Completed Quotations）

定义：每周通过报价 Agent 生成并经专家审核通过的报价单数量。

选择理由：
- 直接反映产品核心价值（帮用户完成报价任务）
- 与商业收入强相关（报价越多 → 成交机会越多 → 订阅续费理由越强）
- 可衡量、可追踪、不可作弊

#### 4.1.3 输入指标（Input Metrics）

| 输入指标 | 定义 | 目标 |
|---------|------|------|
| **报价响应时间** | 从上传需求到生成报价单草案的时间 | ≤ 30 分钟（Phase 1）→ ≤ 15 分钟（Phase 2） |
| **HITL 修改率** | 专家审核时需要修改的比例 | < 30%（Phase 1）→ < 10%（Phase 3） |
| **历史项目匹配成功率** | Agent 匹配到可用已完成计算项目的比例 | > 70%（Phase 1）→ > 90%（Phase 2） |
| **销售独立完成率** | 销售无需技术部协助独立出报价的比例 | > 60%（Phase 1）→ > 90%（Phase 3） |
| **报价→成交转化率** | 报价后最终成交的比例 | 基线测量 → 提升 20% |

### 4.3 Outcome-based Roadmap（基于成果的路线图）

将功能清单转化为"用户成果 → 可衡量标准 → 实现方式"的成果驱动路线图。

#### Phase 1：基础可用（1-2 月）

**用户成果**：销售能独立在 30 分钟内完成一份报价单草案

| 用户成果 | 可衡量成功标准 | 实现方式 |
|---------|--------------|---------|
| 销售上传需求文件后自动提取技术参数 | 结构化参数提取准确率 > 90%，缺失项识别率 100% | LLM + 参数 Schema 校验 |
| 销售通过对话补全缺失信息，无需理解技术术语 | 销售独立补全率 > 70%，对话轮次 ≤ 5 轮 | 对话式交互 + 自然语言提问 |
| Agent 自动匹配到最接近的历史已完成计算项目 | Top-3 匹配命中率 > 80%，数据导入成功率 > 95% | 多路召回 + 重排序 |
| 参数优化后生成可验证的技术方案 | 电磁计算结果满足客户约束，HITL 首次通过率 > 50% | 对接电磁计算引擎 |
| 生成标准化报价单（PDF/Word） | 报价单格式合格率 100%，内容可追溯 | 模板引擎 + 数据填充 |
| 专家审核 ≤ 10 分钟确认或驳回 | 审核控制台可用，审核动作完成率 100% | Web 控制台（HITL） |

#### Phase 2：智能增强（3-6 月）

**用户成果**：报价全链路自动化，从"能出报价"到"报得准"

| 用户成果 | 可衡量成功标准 | 实现方式 |
|---------|--------------|---------|
| BOM 自动拆解，物料成本自动核算 | BOM 自动生成准确率 > 85%，成本核算误差 < 10% | 对接 BOM 引擎 + 物料价格库 |
| 客户修改需求后 Agent 自动更新方案和报价 | 需求变更响应时间 ≤ 10 分钟，方案自动重算成功率 > 80% | 多轮交互 + 增量计算 |
| 报价审批流自动化 | 审批流转时间 ≤ 30 分钟（含技术+商务+总经理） | 飞书审批卡片 + 流程引擎 |
| 报价分析看板上线 | 管理层可查看报价→成交转化率、利润分布、客户分析 | 数据仪表盘 |
| HITL 修改率降至 < 15% | 专家审核效率提升 50% | 知识飞轮积累 + 模型优化 |

#### Phase 3：闭环优化（6-12 月）

**用户成果**：从"报得快"到"报得准、报得赢"，报价成为竞争优势

| 用户成果 | 可衡量成功标准 | 实现方式 |
|---------|--------------|---------|
| 成交率分析驱动定价策略优化 | 报价→成交转化率基线提升 ≥ 15% | 成交率追踪 + 定价策略引擎 |
| 报价时自动查询物料库存和交期 | 交期承诺准确率 > 90% | 供应链实时查询接口 |
| 高置信度场景试点自动通过报价 | 自动通过率 > 30%（HITL 放松） | 置信度评估模型 + 规则引擎 |
| 案例库 > 500 个高质量全链路案例 | 匹配成功率 > 90%，HITL 修改率 < 10% | 知识飞轮持续积累 |
| 新客户 2 周内上线 | 标准化交付流程，onboarding 周期 ≤ 4 周 | 标准化部署 + 配置化 |
