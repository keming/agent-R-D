## 一、调研背景与目的

### 1.1 调研缘起

轨物科技正在面向配电行业成套开关柜厂(盘柜厂)开发AI报价Agent产品。在调研中发现,目前绝大多数成套厂使用的报价软件是利驰软件的产品。为了找准差异化竞争策略,需要对利驰报价软件进行全面深度调研。

### 1.2 调研目标

1. 摸清利驰报价产品矩阵和收费模式
2. 分析利驰报价软件的优缺点
3. 找准我们的切入机会和差异化方向
4. 制定产品方案和落地路线图

## 四、利驰报价软件优劣势深度分析

### 4.1 优点(5项)

1. 数据壁垒极深: 30年积累,1000+品牌,2亿+选型数据,10亿+云端价格
2. 免费策略: ExWinner/SuperWinner永久免费,打不了价格战
3. 识图能力强: 图晓晓AI识图,CAD/PDF/JPG自动出清单
4. 生态完整: 选型-识图-报价-母排-线束全流程打通
5. 品牌信任: 30年老牌,5000+厂在用,正泰背书

### 4.2 缺点(5项,即我们的机会)

**致命问题:太重了**(客户亲口反馈)
- 功能过剩: 报价员只用20%,但被捆绑全套
- 安装麻烦: 需装Office/WPS/.NET/利驰插件
- 学习成本: 新人上手慢
- 界面老旧: ExWinner是Excel插件,交互停留在2010年

**价格体系僵化**
- 云端通用价不是客户实际拿货价
- 无历史价学习,报过的项目不沉淀
- 无协议价支持
- 不联动原材料(铜价涨了不会调)

报价员真实情况: ExWinner配基础价,再手工改Excel出单。

**部署受限**
- 纯SaaS,数据存利驰,三产/国企有顾虑
- 需联网,车间无网不能用
- 无本地化选项

**不是AI Agent**
- 无自然语言交互
- 无智能推荐
- 无问答能力
- 无知识沉淀

**扩展性差**
- 封闭生态,不能对接ERP/CRM
- 无API
- 数据难导出,迁移成本高

### 4.3 利驰未来路线图

| 阶段 | 内容 |
|------|------|
| 当前 | D-Hub报价套件+数字制造 |
| 三阶方案 | 入门->高级(设计+制造)->旗舰版(AIGC,-80%周期) |
| 预判 | 四大Agent:选型/识图/报价/投标 |

警示: 利驰也在往Agent方向走,窗口期有限。

## 七、我们的切入机会

### 7.1 核心竞争策略

利驰做工具,我们做Agent。

| 阶段 | 策略 |
|------|------|
| 初期 | 不抢饭碗,帮报价员更高效 |
| 初期 | 用历史价格精准度做敲门砖 |
| 中期 | 客户发现数据在我们这也准 |
| 后期 | 本地化+数据主权+AI替换 |

### 7.2 四大切入点

| 切入点 | 利驰现状 | 我们方案 | 竞争力 |
|--------|---------|---------|--------|
| 轻量化 | 功能过剩,只用20% | 只做报价,对话3分钟出单 | 强 |
| 价格智能 | 通用价,不认历史/协议 | 历史价+协议价+铜价联动 | 极强(核心差异) |
| 本地部署 | 纯SaaS | 本地,数据不出厂,等保 | 强 |
| Agent交互 | 无AI | 对话+推荐+问答+知识沉淀 | 强 |

### 7.3 竞争武器(利驰打不了)

- 历史价格学习:导入历史报价自动学习,越用越准
- 协议价支持:手动维护,优先级最高
- 铜价联动:LME铜价自动修正导线成本
- 对话报价:不用装不用学,说话就报价
- 本地部署:数据不出厂,符合等保
- 不限账号:团队随便加不加价
- 开放对接:可对接ERP

### 8.1 产品定位

**报价小智** - 盘柜厂AI报价Agent

一句话: 利驰帮你搜价格,我们帮你记住你的价格。

### 8.2 MVP功能

| 功能 | 说明 | 优先级 |
|------|------|--------|

| 外部价格联动 | 供应商价/铜价联动 | P2 |

## 九、价格引擎架构(核心差异)

```
历史报价导入 -> 历史价格数据库
外部价格源 -> 外部价格缓存
     |            |
     +-> 智能定价引擎 <-+
          |
      报价建议价
  = 历史均价x权重 + 市场价x权重 + 协议价覆盖 + 铜价修正
          |
      报价员确认/微调 -> 输出Excel -> 自动存入历史库
```

### 历史价导入

| 数据源 | 方式 | 频率 |
|--------|------|------|
| 历史报价单Excel | 批量导入 | 初次 |
| 利驰ExWinner导出 | CSV导入 | 初次 |
| 每次新报价 | 自动记录 | 持续 |
| 调价通知 | 手动导入 | 按需 |

### 外部价格联动

| 价格源 | 方式 | 频率 |
|--------|------|------|
| 正泰/德力西官网 | 抓取/API | 月/季度 |
| 供应商报价单 | Excel导入 | 按需 |
| 铜价(LME) | 公开行情API | 日 |
| 客户专属协议价 | 手动维护 | 按需(优先级最高) |

## 十、技术架构与落地路线图

### 技术栈

| 层级 | 技术选型 |
|------|---------|
| 前端 | 单页HTML(对话界面+报价单) |

| 外部 | requests定时抓取 |

### 落地路线图

Phase 0(本周): 需求确认+种子数据
- 要20份历史报价单Excel
- 整理柜型规则/元件型号
- 测试DeepSeek提取价格规律

Phase 1(2周): MVP原型
- 对话界面2天 + 报价引擎3天 + 历史价导入2天
- 价格匹配2天 + Excel输出1天 + 报价记录1天

Phase 2(2周): 天使客户定制
- 定制柜型/模板 + 试跑20个项目 + 验收收款

Phase 3(第2月): 价格联动
- 供应商价抓取 + 铜价联动 + 利润预警 + 报价分析

Phase 4(第3月+): 产品化
- 多客户支持 + 标准部署 + 年费定价 + 卖第二家

## 十二、客户话术与销售策略

### 三句话开场

1. 利驰报价准不准?准。但那是对全行业的价格,不是您自己的。
2. 您跟供应商谈了半年的协议价,利驰认不了。但我们认。
3. 您的报价数据在您自己服务器上,不出厂。这才是您的数字资产。

### 针对太重

利驰好不好?好。但您的报价员只用配价算料,其他用不上。装一堆插件最后还是回到Excel手工调。我们Agent说句话就报价,3分钟出单。

### 针对价格

利驰的10亿+价格是公开价。系统导入您过去5年报价单,自动学习您的真实成交价。铜价涨了自动调。

### 针对部署

数据存在利驰服务器=报价历史/客户信息/成本机密交给第三方。我们部署在内网,数据不出厂,符合等保。

### 针对价格(有优势但收费)

ExWinner免费,但40个报价员每人每天1小时手工调价=一年浪费1000+工时。铜价波动丢单=损失几十万。我们一年3-5万不限账号,一个月回本。

### 三句话收尾

1. 利驰做工具,我们做Agent。不冲突,能互补。
2. 先用免费版试试,导入20份历史报价单,3天看效果。
3. 效果好再聊付费,效果不好我请你吃饭。
